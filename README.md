DSA Midterm Lab
____________________

This project contains four C# programs that demonstrate different data structures. Each problem focuses on how a specific data structure can be used to store, manage, and process information.
______________________________________________________________________________
*Problems

# 1. Array – Student Record Management
Uses an **Array** to store student records. The program allows the user to add, display, search, update, and delete student information.

**Data Structure:** Array
_____________________________________________________________________
# 2. Dictionary – Student Lookup
Uses a **Dictionary** to store student records using the **Student Number as the key**. It allows the user to add, search, and display student information.

**Data Structure:** Dictionary
_____________________________________________________________________
# 3. Queue – Student Request Queue
Uses a **Queue** to manage student requests. Requests are processed based on **FIFO (First In, First Out)**, meaning the first request added is the first one processed.

**Data Structure:** Queue
______________________________________________________________________
# 4. Stack – Operation History
Uses a **Stack** to store the history of student-related operations. It follows **LIFO (Last In, First Out)**, meaning the most recent operation is accessed first.

**Data Structure:** Stack
______________________________________________________________________
* Learning Objectives

This project demonstrates how different data structures work and when they can be used:

- **Array** – stores data using indexes.
- **Dictionary** – stores data using key-value pairs.
- **Queue** – follows FIFO.
- **Stack** – follows LIFO.
